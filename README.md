# Derecho Civil · Ayuda Memoria V2

Sitio estático de un solo archivo (`index.html`, autocontenido). No requiere build ni dependencias.

## Despliegue
Subir la carpeta tal cual a cualquier hosting estático:
- **Netlify / Vercel / Cloudflare Pages:** publicar esta carpeta como raíz (sin comando de build).
- **GitHub Pages:** subir `index.html` a la raíz del repo y activar Pages.
- **Servidor propio:** copiar `index.html` al directorio público.

Probar en local: `npx serve .` o `python3 -m http.server`.

Las tipografías se cargan desde Google Fonts (con respaldo local si no hay conexión).
